# Pensieve

A structured thinking companion that helps users understand why they think the way they do through guided dialogue.

## 🧠 Problem

People often get stuck in overthinking and automatic thoughts without realizing it.

## 🎯 Solution

Pensieve uses guided dialogue (Socratic method + CBT principles) to help users:
- identify their thoughts
- understand their origins
- explore alternative perspectives

## 🧩 Core Features

- Guided dialogue engine
- Cognitive insight summary

## 🚧 Current Stage

Low-fidelity prototype & user testing
