> 2026-10-01 更新：Linus 与 Liam 已决定先交付 iOS 私用开发版，不要求跨设备同步、登录或公开发布，并以本机保留完整原始对话及后续版本继续读取已有数据为第一阶段验收。当前实现任务见 [`ios-first-private-build.md`](ios-first-private-build.md)。下文保留此前 Web Preview 的实际实现与验证状态，不再代表当前交付优先级。

用户确认先做自己能用、离开家且 Mac 关闭后仍可用的版本。本文件记录实际实现与验收；产品原则继续以 Institute 的 Pensieve 项目为来源。

## 使用与当前状态

地址：https://pensieve-phone.vercel.app 。Vercel 项目为 `ziyue-lins-projects/pensieve-phone`，与已有网站独立。生产部署 `dpl_66LyAy8yrc7pStQJwC4kapofr9hj` 已就绪。

1. 用 iPhone Safari 打开，选择共享菜单中的「添加到主屏幕」，从新图标进入后再开始记录。Safari 与主屏幕 App 可能使用不同的存储空间。
2. AI 服务配置完成后，在设置输入私人试用口令。首次发送仍会单独说明当前会话经 Vercel 发送到 OpenAI；未选择开启时只在设备保存。
3. 原文在发送后先写入设备，再请求 AI；网络失败可以重试。回顾可修改、暂存、确认，确认后才进入记忆。
4. 定期使用「下载完整备份」存到“文件”。手机与电脑没有自动同步；手机备份格式也不等同于 Mac 目录快照。

线上 AI 尚未启用：自动审批拒绝把本机 OpenAI 密钥及试用凭据上传到 Vercel，理由是尚未获得对该敏感数据和目的地的明确授权。已向用户询问，未重试或绕过。口令与签名密钥仅保存在被忽略的 `.pensieve/mobile-private/`，没有写入 Git、静态资源或部署包。

当前机器直连默认 Vercel 域名超时，经既有代理能访问。iPhone 的网络可达性及实际添加主屏幕仍需真机验收，不能把服务器部署成功视为所有网络均可访问。

## 实现边界

- `VITE_MOBILE_MODE=true` 时，现有聊天界面改用 IndexedDB；Mac 本地文件存储和原云端模式继续保留。每次修改在读写事务完成后才返回成功，两个页面竞争时不让过期 AI 回复覆盖新内容。
- 完整备份包含原文、AI 草稿、用户修改与确认版本。恢复先校验结构、来源关系、版本序号，再在一个事务中合并；同编号不同内容取消整次恢复，不覆盖现有记录。界面导入上限 20 MB。
- Vercel Express 函数仅负责口令验证和 AI 转发，不建立记忆数据库。API Key 仅供服务器使用；当前会话会经过 Vercel 和 OpenAI，平台自身的数据处理政策仍适用。未开启 AI、口令无效或消息无效时不调用模型。
- 签名 cookie 有效期 30 天，生产环境使用 Secure、HttpOnly、SameSite=Strict。更换口令或签名密钥使既有 cookie 失效。登录及 AI 请求有限速；限速器内存位于单个函数实例，不能作为多实例全局用量上限。
- Service Worker 只缓存页面、图标和静态资源，不缓存 API。新版本不强制替换正在使用的页面。设置显示离线准备状态；浏览器清理数据、移除 App 或设备损坏仍可能造成丢失，独立备份不可替代。
- 手机回车用于换行，点击按钮发送；底部导航与安全区域使用现有窄屏布局。

## 时间背景

本机与手机 AI 请求都会携带浏览器时区，服务器提供当前时间和逐条消息记录时间。提示词区分记录时间与事件发生时间，跨日继续时以当时消息的日期解释「今天／昨天」。未知事件日期保留未知；这不是日历、定时提醒或长期跨会话记忆。

## 构建与部署

```sh
npm ci
npm run build:mobile
npm test --workspaces
vercel deploy --prod --yes --local-config vercel.mobile.json --scope ziyue-lins-projects
```

使用专用 `vercel.mobile.json`，`.vercelignore` 排除 `.pensieve/`、全部环境文件和旧 `vercel.json`。`api/package.json` 提供函数构建入口，避免函数构建再次执行根目录旧 `vercel-build` 并覆盖手机版前端。

获得密钥上传授权后，通过 CLI 标准输入把 `OPENAI_API_KEY`、`AI_CHAT_MODEL`、`PENSIEVE_ACCESS_CODE`、`PENSIEVE_SESSION_SECRET` 保存为该项目 Production 的 Sensitive 环境变量，再部署一次。不要上传本机环回代理地址，不把密钥放进命令行参数、日志或前端变量。访问口令至少 24 字符，签名密钥至少 32 字符。

本地隔离验收可用 `npm run dev:mobile-api`（默认 3003）与 Vite preview（5180），使用合成口令和单独浏览器来源；不得将个人记忆用作测试材料。
