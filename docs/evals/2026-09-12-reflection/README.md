# 本地反思对话验收 · 2026-09-12

所有用户话语均为 Agent 编写的虚构场景，不取自个人记忆。模型为本机配置的 `gpt-5.4-mini`。本轮改善已确认的单次反思体验，未扩展到跨会话关联。产品来源仍为 [Institute 的范围确认](/Users/linuslin/Developer/linus-institute/01-Lab/Projects/Pensieve/Notes/Product-Definition/Local-Reflection-MVP-2026-09-11.md)。

## 方法与复现

运行 `npm run eval:reflection -- --live`。脚本通过 `createLocalApp` 的实际消息、回复和确认接口，在独立临时目录中执行三个场景，每个四个用户回合，使用模型的真实回复继续构造上下文。每次回复均不传 `review: true`，因此收尾由模型判断，不是测试代替模型切换状态。

每个场景包含状态、结束回复无问号、原文留存、草稿来源、确认前不生成记忆、修改确认后重新打开和 AI 原稿保留共 10 项自动检查。提前生成回顾时会记录失败，再模拟用户选择“继续聊”，以检查后续回合；不会将提前收尾算成通过。单轮 API 失败不重试，记录错误后停止该场景。

JSON 保存模型名称、提示词 SHA-256、完整合成对话与逐项检查。报告中的问号数只是人工阅读线索：引用用户的问题也会产生问号，无问号的句子也可能是在追问，因此不能把问号数当成提问质量评分。不带 `--live` 不调用模型；这项评估不在普通单元测试中运行。

## 本次结果

| 场景 | 修改前 | 修改后 | 人工核对 |
| --- | --- | --- | --- |
| 区分事实与猜测 | 第 3 轮纠正含义时提前收尾，回复还邀请继续探索 | 前 3 轮聊天，第 4 轮收尾 | 回顾保留“有人说在忙”、提醒时机尚未确定，以及不归纳固定模式 |
| 假设不变成经历 | 状态符合预期 | 状态符合预期 | 回顾明确邀请是假设，保留“不确定现实中是否如此” |
| 修正理解、暂停提问 | 第 2、3 轮提前收尾 | 前 3 轮聊天，第 4 轮收尾 | 回顾保留少睡、嘈杂及只能确定那天很累；未固化人格判断 |

修改前自动检查 27/30 通过，修改后 30/30 通过。证据：[修改前全文](before.json)、[修改后全文](after.json)。每个版本各调用模型 12 次。修改前还出现将“想回家”补成“选择早点离开”的无依据行为，修改后对应回复保留为愿望；提示词因此同时明确愿望、假设与已发生行为的区别。

另用两个未加入上述固定脚本的单轮输入直接调用 `createReflectionAI().reply`，未要求强制回顾：当下已没力气继续时主动收尾，叙述过去的疲惫但今天想继续时保持聊天，两项都符合预期。输入、输出与提示词指纹见[补充检查](closure-probes.json)。这两次不经过本地 API，仅检查模型判断；本轮总计 26 次合成模型请求。

人工核对仍发现可改善之处：部分回复解释偏多，例如将对提醒时机的顾虑扩展成“把别人推远”；虽然随后接受了用户修正，仍需要在真实体验中检查是否令人感到被过度解读。聚会场景的一轮回复含 2 个问号，其中一个是引用原问题，另一个才是实际提问。暂停提问的回复说“先停在这里”，但 `review` 保持为空；之后可以继续改善措辞，避免与结束会话混淆。

本次是有限样本、固定用户脚本、每个版本单次运行，模型有随机性；状态通过不代表对话一定自然、有帮助，也不证明长期效果。先保留这些具体观察，后续根据用户实际体验选择下一项修正。
